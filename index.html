Approach

How data moves through a platform I build.

A medallion approach keeps every stage traceable — from raw source to analytics-ready tables. Select a stage to see what happens there.

Connect to where the data lives

Operational systems rarely agree on format or cadence. I start by mapping each source and choosing batch, incremental or streaming ingestion to suit it.

  • REST APIs, including the 8x8 contact-centre API
  • Oracle and SQL Server databases
  • SFTP file drops
  • Kafka and Fabric Event Streams for streaming

Land it raw, keep it replayable

Bronze preserves source data as received, so anything downstream can be rebuilt. Metadata-driven pipelines and incremental extraction avoid unnecessary full reloads.

  • Fabric pipelines and Azure Data Factory
  • Change Tracking and checkpoint handling
  • ADLS and Delta Lake storage with partitioning

Cleanse, conform and validate

Silver is where data becomes dependable: reusable Python and PySpark components standardise structure, and schema validation catches problems early.

  • Python with Pandas and Pydantic validation
  • PySpark notebooks for scale
  • Reusable transformation modules

Govern as part of the build

Security and quality aren't a final step — they run alongside every layer, so people see only what they should and can trust what they see.

  • Row-level security and lineage
  • Data-quality monitoring
  • Unity Catalog and Azure Key Vault

Deliver to the people who use it

Analytics-ready datasets feed analytics and data science teams, while infrastructure and releases are automated end to end.

  • Analytics-ready Lakehouse tables
  • Terraform-managed infrastructure
  • Azure DevOps CI/CD and YAML pipelines
